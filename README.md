# Brasa · Umbral

Beta jugable **0.12.0-beta.1**.

- [Jugar](https://ayrtoncopter.github.io/brasa-umbral-juego/)
- [Comparar V1 y V2](https://ayrtoncopter.github.io/brasa-umbral-juego/comparar/)

Campaña de 20 encuentros, cuy Guerrero o Mago, equipo, cofres, tienda y forja. La comparación incluye versiones jugables 0.11 y 0.12 con partidas de muestra separadas.

La partida se guarda en el navegador y dispositivo utilizados. El balance y el acabado siguen en revisión beta.

Este repositorio contiene la copia compilada para jugar y el arte que necesita. GitHub Actions publica sus actualizaciones mediante GitHub Pages.
